Operator sign-in

Sign in with your operator account. Only operator accounts can open this console.

Payment queue

Check the wallet or bank statement yourself before confirming. Confirming a payment adds 30 days of access to that user. Access is never granted without your decision here. Open invoices can be cancelled; confirmed, rejected and cancelled records are kept for the audit trail.

Create account

Creates a user account. The operator (admin) role belongs to the single bootstrap admin set in Worker secrets, so no account can be created as admin here. Creates an account directly. Give the initial password to the user through a channel you trust. Use the reset below if they lose it.

Grant access manually

Use only with a verified payment outside the queue (for example, a wire confirmed by phone). Enter a note so the audit trail explains why.

Reset a password

You choose the new password; nothing is generated. Every session of the account ends, so the user must sign in again with the new password. The bootstrap admin password is set in the Worker secret KFX_ADMIN_PASSWORD, not here.
